# 🌸 Atividades de Programação Orientada a Objetos

Este repositório reúne as atividades desenvolvidas durante meus estudos em **Java**, aplicando conceitos fundamentais de **Herança** e **Polimorfismo**.  
Cada projeto foi feito com muita dedicação, buscando unir prática e aprendizado. 💜

---

## ✨ Atividade 01 - Sistema de Usuários

📌 **Descrição:**  
Criação de um sistema orientado a objetos para gerenciar usuários.  
A classe **Administrador** herda da classe **Usuario**, aplicando herança e polimorfismo conforme o diagrama de classes.

📚 **Conceitos aplicados:**  
- Herança  
- Polimorfismo  
- Encapsulamento  

---

## 🚗 Atividade 02 - Sistema de Veículos

📌 **Descrição:**  
Desenvolvimento de um sistema para gerenciar veículos.  
A classe **CarroEletrico** herda da classe **Carro**, demonstrando como estender funcionalidades e aplicar polimorfismo.

📚 **Conceitos aplicados:**  
- Herança  
- Polimorfismo  
- Sobrescrita de métodos  

---

## 📩 Atividade 03 - Sistema de Notificações

📌 **Descrição:**  
Implementação de um sistema para envio de notificações por **e-mail** e **SMS**.  
As classes **NotificacaoEmail** e **NotificacaoSMS** herdam da classe **Notificacao**, aplicando polimorfismo para diferentes formas de envio.

📚 **Conceitos aplicados:**  
- Herança  
- Polimorfismo  
- Construtores especializados
